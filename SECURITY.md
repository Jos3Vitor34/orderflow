# Relato de vulnerabilidades

Evite abrir issues públicas com credenciais, provas de exploração ou dados de
terceiros. Após a publicação no GitHub, use **Report a vulnerability** na aba
Security do repositório, se a opção estiver disponível. Caso não exista canal
privado, abra uma issue sem detalhes exploráveis solicitando um meio de contato
privado; não envie segredos nessa issue.

Este é um projeto de portfólio executado localmente, sem serviço público ou SLA de
resposta. Revogue ou rotacione imediatamente qualquer credencial real que você
suspeite ter sido exposta. Não use chaves Stripe live neste projeto.
